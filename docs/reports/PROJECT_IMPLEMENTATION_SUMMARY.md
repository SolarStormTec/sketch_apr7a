# SmartJet v2.0 - 项目实现总结

## 🎯 项目概述

SmartJet v2.0是基于ESP32-S3的智能发电机控制器，采用ESP-IDF框架开发，具备完整的IoT功能和工业级稳定性。该项目将传统汽油发电机升级为智能化设备，支持远程监控、自动启停、云端管理等功能。

## 🔧 编译和使用

### 环境要求
```bash
ESP-IDF v4.4+
ESP32-S3芯片支持
CMake 3.16+
```

### 编译步骤
```bash
# 1. 设置ESP-IDF环境
source $IDF_PATH/export.sh

# 2. 设置目标芯片
idf.py set-target esp32s3

# 3. 配置项目
idf.py menuconfig

# 4. 编译项目
idf.py build

# 5. 烧录和监控
idf.py flash monitor
```
